
# SPB Forever — Fan Tribute Website

A responsive fan website dedicated to Dr. S. P. Balasubrahmanyam.

## Technologies used

- HTML5
- Bootstrap 5
- CSS3
- JavaScript
- YouTube embedded player
- Google Fonts

## Project structure

- index.html — Website structure and content
- style.css — Website design and responsive layout
- script.js — Playlist, search, tribute and sharing functionality
- assets/ — Images used by the website

## How to run

1. Download and extract the project folder.
2. Keep all four project files and the assets folder together.
3. Open index.html in a web browser.
4. Connect to the internet for Bootstrap, Google Fonts and YouTube.
5. Click songs in the playlist to change the selected playback position.

## Features

- Responsive navigation bar
- SPB biography and career timeline
- Embedded YouTube music player
- Searchable song playlist
- Photo gallery
- Musical legacy section
- Tribute message buttons
- Website sharing option

## Customization

Edit index.html to change the text, links and songs.

Edit style.css to change colors, spacing, fonts and animations.

Edit script.js to change playlist interactions and button behavior.

Replace images inside assets/ and update the corresponding image paths.
